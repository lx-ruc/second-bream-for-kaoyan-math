### 环境坑（都是实测踩出来的，下次直接照方抓药）

1. **IDE 每次启动弹「更新提示」原生弹窗**，会堵死全部自动化指令——现象是 WS 连得上但 `Tool.getInfo`/`currentPage` 全部超时。配方：osascript 把 `wechatdevtools` 进程设为 frontmost，再用 CGEvent 点击「稍后再说」**两次**（第一下只是激活窗口，macOS 点击穿透保护）。窗口位置会漂，按「项目窗口中心 + 下方约 135pt」估算。`scripts/click.swift` + `click.bin` 就是干这个的。
2. **touristappid + 未登录 IDE = App 域自动化死路**：裸 WS 探测证实 `Tool.getInfo` 秒回、`App.getPageStack` 永远无响应。IDE 日志特征：`errcode 41001`、`getNewTicket empty ticket`。必须扫码登录后 App 域才挂得上。`automator.launch` 在未登录时还会因 `Tool.getInfo` 没有 SDKVersion 在 `cmpVersion` 里 undefined.split 直接炸（`checkVersion` patch 掉即可，scripts/test-e2e.js 已带）。
3. **`cli auto` 在 IDE 冷启动时只到项目列表页**，不直接开项目窗口。顺序：`cli open --project` → `cli auto --project --auto-port 9420` → connect。
4. **不要乱点 IDE 工具栏**：点错会把模拟器面板拆成独立窗口，且窗口布局存在 `WeappLocalData/localstorage_*.json` 里跨启动记忆，拆坏了很难复位（`界面>模拟器` 菜单、panelShow 字段都没救回来；`工具>居中显示所有窗口` 能把屏幕外的窗口捞回来，但 z 序救不了）。教训：屏幕级自动化只点**动态计算出的坐标**，别按上一次截图的坐标复用。
5. ghcr.io / pkg-containers.githubusercontent.com 直连不通（代理 127.0.0.1:7898 没开），brew 装不了东西时改用 `swiftc` 现场编 CGEvent 工具（终端有辅助功能权限，子进程继承）。
