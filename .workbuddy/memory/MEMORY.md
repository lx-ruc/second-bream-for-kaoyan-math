# 第二大脑项目 · 长期记忆

## 仓库与协作
- 远程：https://github.com/lx-ruc/second-bream-for-kaoyan-math
- 多机开发：**每次动手前先 `git pull`**；**提交时全量提交**（含 `.workbuddy/memory/`），另一台机器的 WorkBuddy 靠仓库延续上下文。
- 语料来源：作者本人的腾讯文档空间（三卷真题索引 / 75 篇逐题精讲 / 「为你代研」考频表），非爬取。

## 产品
考研数学纠偏工具，参赛「AI 创造公开赛 · 考研小工具限时挑战」（截稿 2027-01-06）。核心不是错题本，是「这道题该不该做」。方案见 `设计/考研数学第二大脑-设计方案.html`（v0.3）。

## 硬约束（用户纠正过，别再犯）
1. 模型不判断「重不重要」，重要性只能由真题统计得出。
2. 题 ↔ 思路族的对应由**用户点选**。精讲解析里的「法一／法二」是同一道题的**不同解法**，不是思路族编号——这条例错两次，用户明确纠正过。
3. 熟练度只记四档行为事实（独立做出 1.0 / 提示后 0.6 / 看答案 0.2 / 还是不会 0），不采自评。
4. 考频表的 239 个考点与真题索引的 92 个考点**名称匹配仅 8%**，`泰勒公式`会错配到「根据通项公式求极限」，不能自动合并，必须人工映射表。
5. 三卷共用一棵超集考点树；画像按五个池聚合（高数三卷分池、线代三卷合并、概率一三合并）。

## 语料事实
1224 条题坐标 / 92 考点 / 75 篇精讲 / 475 条题干 / 239 行考频。
**线代 270 题、概率 180 题零精讲**（整学科缺口）。坐标题是热度统计的分母，不能删。
仅有坐标的题在界面里要显式标「仅坐标」，否则用户会当成 bug。
