## 调研 bestzixue.com（知能行考研数学）能否与我们结合

用户问「这个网站的功能能不能和我们的结合起来」。实抓官网 + 专家团（架构/合规）双评估，结论如下。**纯评估，未改任何代码，verify 无需重跑。**

### 本质判断：两类产品，不是同类
- 知能行回答「接下来该练什么」= 神经网络 AI 教练（出题+规划+督学的主动教练，付费闭环）。
- 我们回答「手上这道题该不该做」= 判题/纠偏/过滤的决策过滤器（本地白盒、可核对）。
- 所以不存在搬功能这回事；能借的是通用理念表达，不能借的是黑箱算法/题库/宣传口径。

### 7 项功能三档处置（详见对话内对标图）
- 可借鉴·理念层：①「省时间」叙事→强化「少做无效题」（接 intake/diagnose 的 skip/edge 话术）；②三大症状自检→诊断页做**导航入口**（结果不入库、不影响 mastery，守红线③）；③错题+新题混合复习节奏（review 展示层）；④分值「年均 X 分」物理量表达（prior 页，py 已有）。
- 需改造·数据层：掌握等级条只能由四档行为事实演化、不采自评、不承诺「满格=某册90%」；按考点定向筛**自有**真题（不含 660/880/1000/1800）。
- 不该做·红线层：神经网络黑箱判重要性（违红线①）、「满格=某册90%」/「能力条量化考场发挥」（不可核对的编造信号）、收录习题册题（版权不在我方）、督学群/小时级计划（重运营）、用题库权重校准考频（违红线④）。

### 合规评估（合规官实测，三层）
- 功能理念借鉴：**低风险**（通用教育产品概念，理念相似≠表达相似；我方白盒路径反而差异化）。
- 内容/题库借鉴：**高风险·一票否决**——「独家练习题」是对方登录墙后核心资产，禁止抓取/复制；真题及 660/880/1000/1800 的权利归属复杂【待确认】，对方精讲/解析/编排是汇编成果，整体复制风险高。
- 品牌/宣传语借鉴：**高风险**——48万+用户、正确率90%、10倍、名校背书均无我方出处，触发虚假宣传核查，一个字都不能引入。
- 仓库实测：`kp.js` 内 170 处 docs.qq.com 链接是「语料源自作者本人空间」的物证；全仓扫描知能行/bestzixue/48万/10倍等**零命中**（唯一 90% 是 ocr-text.js 技术注释误报）。
- 结论：坚持自有语料路径（真题索引+逐题精讲+考频表）**已规避内容/宣传两层主要风险**；合规层面 NoOne，无需为规避知能行改代码。
- 审核：功能相似本身不触发驳回；我方先体验后授权、无强制登录是加分项。待确认项：语料权利链、真题版权状态、商标检索、隐私协议声明相册/图片用途、死链 e2e 实测。

## 作答沉淀与分析页并入 mp（15:47 用户定方向并落地）

用户需求原话「扫描做题是一部分，要把用户的题目和做题过程保留到小程序进行分析」。经三轮 AskUserQuestion 收敛（关键：否掉 92 道选择题库、否掉本地图像增强扫描、扫描改用现有云 OCR），最终实现：

### 裁决与边界
- **数据源唯一**：`ekb.records.v1`（拍照/粘贴沉淀的题 + 四档掌握度）。不引入 92 道选择题库、不引入其 32 条真题摘要相似度算法、不要段位/打卡。用户多选保留三样：答题记录/得分、错题本+连对移出、六维能力雷达。
- **得分四档加权**（1.0/0.6/0.2/0.0，**绝不二值对错**）——压成对错会丢「提示后 vs 看答案」的区别，违用户红线。
- **同一题稳定 key = 题干归一哈希**：拍照题无 questionId，用 normText 归一（多归半角括号，因 OCR 全/半角混用）+ djb2 哈希；题干缺失退 img/id。
- **六维口径全部按本项目语义重定义**（不用新小程序章节/难度口径）：独立做出率 / 平均掌握度 / 高频考点掌握(只由 engine.heat 的 n6 真题统计判定) / 近期掌握(最近10条) / 覆盖广度(去重考点÷真题树92) / 纠错提升(同题从低到1.0)。每维 value 0-100 + base 样本量；空数据全 0 且页面写明「0=没记录不是掌握差」「没记≠没掌握」「不判断该考点重要/该做」。
- 入口：tabBar 满 5 项，从 diagnose 页 `goProgress()` navigateTo，新页 `pages/progress/progress`。
