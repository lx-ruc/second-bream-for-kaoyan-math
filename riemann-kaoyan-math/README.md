# 黎曼考研刷题

考研数学刷题微信小程序（原生开发，无框架、无云服务，数据全部保存在本机）。

## 功能

| 模块 | 说明 |
|---|---|
| 题库目录 | 按「高等数学 / 线性代数 / 概率统计」分三部分，章节显示 `已做/总数` 与正确率，可折叠 |
| 答题 | 练题 / 背题双模式，单选、多选、判断，答题卡跳题，收藏 |
| 计分 | 答对得该题满分（10/15/20），曾做错再答对额外 +5 纠错奖励，答错 −5；累计总分对应段位 |
| 错题集 | 按章节分组，可查看 / 重练；同题连答对 2 次自动移出 |
| 能力图谱 | 六维雷达：计算能力、解题能力、知识储备、应变能力、选填能力、大题能力 |
| 真题相似度 | 每道题给出与历年真题考点的相似度与 Top3 匹配 |
| 扫描做题 | 拍照/相册 → 去阴影增强或二值化 → 保存到本地并预览 |
| 我的 | 学习统计、累计得分与段位、近 7 天柱状图、每日目标 |

## 目录结构

```
├── project.config.json              AppID 与编译配置
├── assets/tabbar/                   tabBar 图标（PNG）
├── components/math-block/           公式渲染组件（文本/极限/分式/矩阵）
├── pages/
│   ├── index/                      题库目录（首页）
│   ├── practice/                   答题页
│   ├── result/                     答题报告
│   ├── wrong/                      错题集
│   ├── favorite/                   收藏
│   ├── scan/                       扫描做题
│   └── profile/                    我的
└── utils/
    ├── questions.js                题库（92 题 / 3 科 / 14 章）与目录、能力计算
    ├── store.js                    本地数据层（作答记录、错题、收藏、得分、打卡）
    ├── score.js                    计分与段位规则
    ├── similarity.js               真题相似度算法
    ├── exam-bank.js                真题考点摘要库
    ├── image-proc.js               扫描件图像处理（灰度/拉伸/大津二值化）
    ├── scans.js                    扫描件本地存储
    └── nav.js                      自定义导航栏尺寸
```

## 本地运行

1. 用微信开发者工具打开本目录（`project.config.json` 已配置 `miniprogramRoot: "./"`）。
2. AppID 为 `wx3b8baf398bf449d2`，如换成自己的可在此修改。
3. 无需 npm 安装、无需后端。

## 数据存储

全部数据保存在小程序本地 Storage，不上传服务器：

- `riemann_records_v2` 每题作答记录（结果 / 时间 / 次数 / 连对次数）
- `riemann_wrong_v1` 错题集
- `riemann_favorite_v1` 收藏
- `riemann_stats_v1` 统计、得分、每日目标
- `riemann_scans_v1` 扫描件元数据（图片本体存本地文件目录）
