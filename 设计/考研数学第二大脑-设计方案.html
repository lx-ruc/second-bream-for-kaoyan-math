01四条判断

原设想里没有明说、但决定成败的四件事。

错题本是点，这是图
痛点从来不是"这道题我错了"，而是"我在极限存在性上系统性不行"。产品的价值单位是考点，不是题目。
记录成本决定留存
手打一道题的公式要 3 分钟，拍照识别要 8 秒。OCR 不是附属功能，是这个产品能不能被用起来的命门。
最大的浪费不是做错，是做了一堆不考的
考研数学有明确的命题惯性：重基础、重计算、反技巧。市面资料里大量偏题、怪题、竞赛技巧题，学生花在上面的时间，真题一分都不会考。
不做自动解题
拍照搜题已经有人做了，且会诱导抄答案。我们只做归档 + 归因 + 纠偏，这是 OCR 可靠性的安全区，也正好对应"省时间"。
一句话定位：错题本记录"我错了哪道"，第二大脑回答"我弱在哪、下一步练什么、哪道不该练"。

03四个关键决策

每条都写了取舍，方便你推翻我。

决策一：熟练度不靠自评，靠行为信号

用户自评"我大概会了"必然虚高。录入时只问一个动作性问题：

作答结果（四选一）得分含义
独立做出1.0思路自己走通，无需提示
提示后做出0.6卡在某一步，看提示后自己走完
看答案才懂0.2解法看得懂但想不到
看完仍不会0.0知识点缺口，不是技巧问题
单题熟练度 = 近 3 次作答加权均值 × 0.9^(距今天数 / 14) 考点熟练度 = 该考点下所有题熟练度的「中位数」（不是均值，避免单题极值拉偏）

中位数这个选择值得说明：一个考点下常有 20 道题，其中 3 道压轴题永远做不出。用均值会让"其实已经掌握"的考点显示得很低，用户会失去信任。

决策二：考点树只建一棵超集，绝不建三棵

如果让模型自由生成标签，你会得到"极限的计算""求极限""极限求解"三个语义相同、无法聚合的标签，整个索引就废了。三卷同理——三棵树 = 三套考点 ID = 三份画像无法复用，用户二战换卷，历史数据也搬不过去。

  • 建一棵超集树：三卷考点的并集，叶子约 380 个（线代 60 / 概率 70 / 高数 250），一份 ID 体系。
  • 用 syllabus 表标每个考点在三卷的 in_scope，即"一树 + 三张覆盖层"，不做三棵树。
  • 模型输出 top3 候选考点 + 置信度，只能从树里选，不能造新词；置信度 < 0.75 强制人工确认。

决策三：容量上限是产品机制，不是限制

原设想写了"有容量上限"，但没定义上限带来什么行为。我的设计是把它变成维护熟练度的动力：

  • 免费 300 题。超限时不是粗暴拦截，而是给两个出口：已掌握归档（熟练度 ≥ 85 且 30 天未错）和 偏题一键清理（贴合度 < 35）。归档后都不占容量，但仍可搜索。
  • 这样用户会主动关注"哪些考点我已经拿下了"，而不是无脑囤题。

决策四：双端分工，不是双端对等

小程序 = 采集 + 复习
拍照、确认、纠偏、今日清单。场景在书桌前、在通勤路上，单手可完成。
Web = 批量体检 + 诊断
大屏热力图、批量拖拽上传、题库表格化体检、导出。场景在电脑前做周复盘。
纠偏进来后，八周内做两套完整功能已经不可能。Web 端整体推迟到赛后，仅保留一个只读诊断页用于录视频。取舍见第 08 节。

04纠偏：以 15 年真题为准

核心不是"AI 觉得这题好不好"，是"这道题在你的考卷上出现过吗、以这种方式出现过吗"。

4.1 基准从哪来：真题库 → 命题画像

先把 15 年真题做成一份结构化语料。三卷全覆盖后，总量仍在这个量级——这是好消息。

规模

每道题的标注

三卷的大纲差异很不均匀：高数差异最大，线代几乎一致，概率只有数一数三考。所以画像不能简单地"按卷存三份"，要按样本可合并性分池。

这个合并不是偷懒，是为了让冷考点有统计意义。"二次型正定性"在高数分卷下每年只出 1–2 道，单卷 15 年攒不到 10 个样本；但线代三卷合并后，同一个考点一年有 4–6 道，15 年就是 60+ 个样本，考法分布才站得住。

两个标注维度要定义清楚，否则聚合不出来

维度枚举（固定，不许自由发挥）例子
考法类型 概念辨析 / 直接计算 / 证明（存在性·不等式·等式） / 应用题 / 反例构造 / 跨章节综合 "极限存在性判定"这个考点，15 年 9 次考查里 8 次是直接计算，0 次是证明
思路族 每个考点预设 3–5 个标准思路，如极限计算 = 等价无穷小 / 泰勒展开 / 洛必达 / 夹逼 / 定积分定义 真题标准路径是"先判型→等价替换→泰勒"，如果唯一解法是竞赛级放缩，属族外
这一节最要紧的一句：模型不判断"这题重不重要"，模型只做标注；"重要性"由真题统计算出来。任何让模型直接输出"建议跳过"的设计，都会退化成模型的好恶，学生会立刻不信任。

4.2 两层判定：先查真相近邻，再让模型标注

纠偏的准确率不能押在模型的自由发挥上。我把它拆成两层，能用检索解决的绝不用模型：

A 层 · 真题最近邻（主力，高可信）
同考点内做题干向量检索，相似度 ≥ 0.85 时判定为"真题同源变式"，直接继承那道真题的考法/思路标签，并告诉用户"这是 2019 数一第 15 题的变式"。这一层不需要模型判断，结论可核对。
B 层 · 模型标注（兜底，需证据）
匹配不上真题时，模型按固定枚举打「考法类型 + 思路族 + 难度」，且必须给出判定依据句。置信度低于阈值时标注"判定不确定"，不做强结论。

这样设计的好处是：产品里最有说服力的那部分结论（"你就是 2019 那道题的变式"）来自检索，可复现；模型只负责长尾。

4.4 贴合度公式与分档

贴合度 = 100 × (0.30 × 考点热度 + 0.30 × 考法匹配 + 0.25 × 思路匹配 + 0.15 × 难度匹配) 超纲 → 直接置 0，不参与加权 权重理由：考点热度与考法匹配各占三成，因为它们回答"考不考"；思路匹配占 2.5 成， 回答"思路正不正"；难度只占 1.5 成，因为难度偏离的代价最小（做难题只是费时间，不误导）
区间判定给用户的话
85–100真题同源优先做，这是命题人偏好的考法
65–84常规练习放心做
45–64轻微偏离可以做，但别把它的套路当标准解法记住
25–44考法偏离看思路就行，不必刷同类
< 25偏题建议跳过，省下的时间做真题
0超纲你的科目不考，直接跳过

时间衰减：不是 15 年等权

近 5 年（2021–2025）× 1.5　|　6–10 年（2016–2020）× 1.0　|　11–15 年（2011–2015）× 0.7

2021 年考研数学题型结构调整后（客观题分值上升、解答题数量减少），命题的考法重心明显往"计算准确 + 概念辨析"偏。把 2012 年的考法和 2024 年等权，会让画像失真。

三卷差异在这个卡片上直接可见。同一条三重积分题：数一用户看到「同源 88，现在就做」，数二用户看到「超纲 · 直接跳过」。这不是两个功能，是同一套 syllabus 白名单在起作用——也是视频里最好演示的一下。

4.6 三个入口，别只做成一个弹窗

① 录入时
确认页即时显示贴合度，超纲题标红。作用：不让垃圾进库，减少后续清理成本。
② 题库体检
一键扫描历史全部题目，输出偏离清单，支持批量归档。作用：清存量，也是老用户回家的理由。
③ 诊断页
练习时间分配统计——"本月 62 题里 14 题偏离，占练习时间 31%"。作用：给结论，不只给标签。

第 ③ 个入口是我最看重的。「你 31% 的练习时间花在真题不会考的题上」——这一句话的说服力，比任何热力图都强，也是视频里最该给特写的一屏。

4.7 诚实边界

  • 每条结论必须挂 2–3 道真题做证据，不能只有分数。用户点开能对照，才叫纠偏；点不开，就是我说的算。
  • 用户可否决。点"这题我觉得该做"，进 corrections 表，并把该考点从后续推荐里放宽一档。老师指定的题永远优先于算法。
  • 冷门考点的判定要降置信度。合并池里样本仍 < 5 时，只输出"数据不足"，不硬下结论。
  • 定位是时间分配建议，不是"这题是错的"。文案上永远不否定用户的资料和老师，只说"性价比"。
  • 真题标注本身有主观性。精标集双人独立标注，算一次一致性系数；不可接受就回到标注手册改定义，别急着上模型。

索引策略

  • 标签索引：question_kp 支撑考点聚合（熟练度、热力、时间分配）。
  • 向量索引：题干 embedding 用于两件事——题内去重（"这题你 3 个月前做过"）、真题最近邻（纠偏 A 层）。三卷共用同一索引，科目只影响白名单与画像池。
  • 画像预计算：exam_profile 离线跑批，不进实时链路；实时只做最后一步加权。
  • 不做全量重算：熟练度在 attempts 写入时增量更新，看板读缓存。

07AI 流水线

目标不是"识别得准"，是"识别不准时用户不烦，判定不准时用户能查证"。

1预处理裁边纠偏、去阴影、二值增强
2多模态解析输出结构化 JSON
3真题检索最近邻 ≥0.85 直接继承
4风格标注考法 / 思路族 / 难度
5加权判定白名单 → 贴合度 → 证据

模型输出的 JSON 结构固定，不允许自由发挥：

{ "stem_latex": "…", // 题干，唯一正文 "answer_latex": "…", // 标准答案（可选） "kp_candidates": [ // 必须来自超集树，三卷同一个 ID {"kp_id": "H1-03-02", "confidence": 0.86} ], "style": { // 只允许固定枚举 "method_type": "证明", // 概念辨析|直接计算|证明|应用题|反例构造|综合 "thinking_family": "族外", // 主族|次族|族外 "difficulty": 4, "calc_load": 3 }, "stuck_options": ["需构造辅助函数", "需分左右极限讨论"], "quality_flags": ["handwriting_detected"] }
必须诚实的两条：① MVP 只承诺识别印刷体题干，手写解题过程的公式识别远不到可用水平，手写卡点让用户用语音或一句话补充；② 纠偏给的是建议，不给"你错了"的断言，所有结论必须可展开到真题证据。

成本控制

免费额度
300 题（与容量上限一致，用户心智只有一个数字）
单题成本
多模态单次调用控制在 ¥0.02 内；纠偏的 A 层是向量检索，几乎零成本
真题库
1,000 题 × 一次标注 = 一次性成本，远低于每用户每题都跑模型
降级策略
解析失败重试 1 次；仍失败则保留原图 + 手动填三字段入库，不让用户卡在门外

08八周排期

2026-11-06 → 2027-01-06。三卷全覆盖后，产品结构几乎不变，真正的增量在真题标注。

W1 · 双基线并行超集考点树 v1（高数 200 叶子 + 线代 60）+ 精标 Tier 1 启动（2021–2025 三卷约 340 题）
W2 · 画像与链路五个画像池跑通 + 三卷大纲覆盖表 + 拍照识别 pipeline
W3 · 主链路确认页（含纠偏卡片 + 科目白名单）+ 入库 + 容量与归档
W4 · 题库题库列表 + 详情 + 按卷筛选 + 按贴合度排序
W5 · 纠偏全量Tier 2/3 预标与抽检 + 题库体检 + 批量归档 + 换科目重算
W6 · 诊断章节热力 + 反复卡点 + 分卷练习时间分配
W7 · 复习与补齐今日清单（按贴合度优先）+ 概率考点树 + 冷考点置信度降级
W8 · 收尾性能、录视频、投稿
1,000 道真题的标注，靠分层而不是硬啃：
Tier 1 精标 —— 2021–2025 × 3 卷 ≈ 340 题，逐题人工复核，约 6 小时（撑起 A 层最近邻和高权重判定）
Tier 2 半标 —— 2016–2020 ≈ 340 题，模型预标 + 10% 抽检，约 1 小时
Tier 3 粗标 —— 2011–2015 ≈ 320 题，模型预标 + 只抽检高频考点，约 40 分钟
理由：时间衰减后 2011–2015 的权重只有 0.7，误差影响最小，不值得花同等力气。
被砍掉的：Web 端（只保留一个只读诊断页用于录屏）、SM-2 自动排程（降级为手动标记待复习）、同考点变式推荐。理由：纠偏是差异化命门，宁可少一个端，也要把真题标注质量做上去——这一块做虚了，整个功能就变成模型随口给分。

09视频脚本

横版，90 秒。评委只看前 20 秒决定要不要看完，所以纠偏提前到 18 秒出场。

0–8s
桌上三本翻烂的错题本。「我记了 800 道错题，还是不知道自己弱在哪。」
8–18s
手机对准真题，快门。6 秒出结构化卡片：题干、考点、卡点。
18–38s
翻到一道习题册的怪题，贴合度跳出 38 · 考法偏离。展开证据：该考点 15 年 9 考，0 次考放缩证明。「你花在这类题上的时间，真题一分都不会考。」
38–52s
同一条三重积分题，切到数二 → 立刻变成「超纲 · 直接跳过」，切回数一 → 「同源 88」。一键清理全部偏题，容量条回落。
52–58s
连拍 5 张批量入库，进度条扫过。
58–74s
诊断页：「本月练习时间 31% 花在偏离题上」。切章节热力：极限存在性 42%。点进去 7 题，4 题卡在"左右极限未分讨论"。
74–86s
生成今日清单：12 题，全部贴合度 ≥ 82。开始重练。
86–90s
收尾字幕：「错题本记住你错了哪道，第二大脑记住你弱在哪，还告诉你哪道根本不用做。」

10风险清单

按严重度排。前三条会直接决定这个功能是资产还是负债。

风险严重度处置
真题标注质量不过关，画像失真高先定标注手册再标；精标集双人独立标 + 一致性检验；不合格就改定义，不上模型
1,000 道三卷标注量压垮排期高Tier 1/2/3 分层；时间衰减让低权重年份可以粗标；先保近 5 年三卷
三卷差异只做"考/不考"，忽略深度差高syllabus 只判在不在范围；深度与考法差异交给分卷画像表达，两者别混在一张表
冷考点样本太少，判定没有统计意义中线代三卷合并、概率一三合并；合并后仍 < 5 时只输出"数据不足"
用户认为算法在否定自己的老师中文案只用"性价比"表述；用户可否决；老师指定的题权重最高
手写公式识别不准中明确不承诺，只认印刷体；手写卡点用语音补一句
八周做双端 + 三卷 + 纠偏中Web 端推迟到赛后，只留只读诊断页
录入仍是负担，拍两张就弃中把「8 秒一题」当硬指标做性能预算，超时就砍功能
