# 考研数学第二大脑

一个把「刷过的题」变成「薄弱考点地图」的工具。核心不是错题本，是**纠偏**：用 15 年真题的考法分布，告诉你手上这道题到底该不该做、该做到什么程度。

面向「AI 创造公开赛 · 考研小工具限时挑战」（截稿 2027-01-06）。当前形态：微信小程序 + 可离线打开的原型页。

## 数据从哪来

全部来自作者腾讯文档空间，非爬取：

| 语料 | 规模 | 用途 |
|---|---|---|
| 三卷「全考点真题索引」2009–2026 | 1224 条题坐标、92 个考点 | 热度统计的分母 |
| 75 篇逐题精讲 | 475 道题带 LaTeX 题干/答案/解析 | 题干匹配、标准思路族 |
| 「为你代研」考频统计表 | 239 行、40 年 | 独立参考页，**不参与判定** |
| 880 / 660 习题册映射 | 三卷各一套 | 尚未接入 |

**关键事实：1224 题里只有 475 题有题干。** 线代 270 题、概率 180 题全部只有坐标，没有精讲。这是整学科缺口，不是随机缺失。坐标题仍然是热度统计的分母，不能省。

## 怎么跑

### 小程序

用微信开发者工具打开 `考研数学第二大脑/mp`。`appid` 目前是 `touristappid`，上传前需换成自己的。

首次拉代码先装依赖（`node_modules` 不入库）：

```bash
cd 考研数学第二大脑/mp
npm install
```

改语料后重新生成数据，改代码后跑校验：

```bash
python3 scripts/build_data.py   # 语料 → data/*.js
npm run verify                  # 静态校验 + 回归测试
```

`npm run verify` 会检查：JSON 合法性、页面与 tabBar 配置、WXML 标签配对、模板引用的字段是否存在于 `data`、事件绑定是否有对应函数、require 是否断链、WXSS 花括号。**它不等于能跑**——编译期语义和真机布局只有微信开发者工具能验。

### 拍照识题怎么工作

`拍照 / 相册截图 / 微信图片` 三种来源都走 `wx.chooseMedia` 与 `wx.chooseMessageFile`，先压到 1200px 再送进云服务的视觉模型。

关键设计：**识别结果只用于检索，不用于阅读**。数学公式的识别精度撑不起「把题面读给你看」，但撑得起「在 475 道真题里找到这是哪一道」。命中之后就换成库里的标准题干，识别时的错字全部丢弃。

找原题的阈值 0.55 是实测出来的：475 道真题模拟 12% 漏字时，命中自身的相似度中位 0.639、p05 0.489，而错配到其它题的最高相似度 p95 只有 0.415。取 0.55 → 召回 86%、误报 3%。宁可不认，也不认错题——认错会把错题记到别的考点上，比不识别更糟。

### Web 原型

```bash
cd 考研数学第二大脑/v2
python3 ingest.py     # 仅在 raw/ 更新后需要
python3 build.py      # 产出 dist/真题库原型.html
```

## 设计上不能动的几条

1. **模型不判断「重不重要」**，重要性只能由真题统计得出，可核对。
2. **题与思路族的关系由用户点选**，不让模型猜。精讲里的「法一/法二」是同一道题的不同解法，**不是**思路族编号，别混。
3. **诊断用中位数不用均值**：每个考点都有几道压轴题永远做不出，均值会拖垮一个已掌握的考点，用户看到就会不信这个数。
4. **熟练度不采自评**，只记四档行为事实（独立做出/提示后做出/看答案才懂/还是不会）。
5. **考频表的 239 个考点与索引的 92 个考点不能自动合并**：名称匹配只有 8%，`泰勒公式` 会被错配到「根据通项公式求极限」。要合并必须人工做映射表。

## 已知限制

- **公式是 Unicode 近似，不是排版**：小程序没有 DOM，跑不了 KaTeX。`xᵐ`、`∫₀ˣ`、`lim_{n→∞}` 这类可用；矩阵、分段函数会失真。后续换 SVG 图或后端渲染。
- **题干只有 475 题**，粘线代/概率的题匹配会失准，需手动选考点（产品里已兜住）。
- **热度归一化系数是拍的**（n6/8），真实语料做大后要重校。
- **拍照识别未经真机验证**：模型选型、图片消息格式、`for await` 流式消费都按 SDK 类型定义写对了，但没在真机上跑通过。若首调报 `request_*`，先怀疑网关是否接受 base64 data URL——改法是先传云存储再给签名 URL。
- **只认印刷体**：手写解题过程识别不可用，产品上也没打算认。用户只需点「卡在哪条思路」，不需要把过程打出来。
- **图片存本地 `USER_DATA_PATH`**，删记录会删图，无人引用的图在进入录题页时清理。

## 协作约定

多机开发。**每次动手前先 `git pull`，看清最新代码再改；提交时全量提交，不要只提改动的一部分**——另一台机器上的 WorkBuddy 要靠仓库延续上下文，包括 `.workbuddy/memory/` 里的工作记忆。

两个例外（已在 `.gitignore` 排除，属于设备本地状态，提交会互相覆盖）：`.wbapp_*.genie` 应用卡标记、`.workbuddy/applications.yaml` 应用归属记录。
