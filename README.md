# 考研数学第二大脑

一个把「刷过的题」变成「薄弱考点地图」的工具。核心不是错题本，是**纠偏**：用 15 年真题的考法分布，告诉你手上这道题到底该不该做、该做到什么程度。

面向「AI 创造公开赛 · 考研小工具限时挑战」（截稿 2027-01-06）。当前形态：微信小程序 + 可离线打开的原型页。

## 数据从哪来

全部来自作者腾讯文档空间，非爬取：

| 语料 | 规模 | 用途 |
|---|---|---|
| 三卷「全考点真题索引」2009–2026 | 1224 条题坐标、92 个考点 | 热度统计的分母 |
| 75 篇逐题精讲 | 475 道题带 LaTeX 题干/答案/解析 | 题干匹配、标准思路族 |
| 「为你代研」考频统计表 | 239 行、40 年 | 独立参考页，**不参与判定** |
| 880 / 660 习题册映射 | 三卷各一套 | 尚未接入 |

**关键事实：1224 题里只有 475 题有题干。** 线代 270 题、概率 180 题全部只有坐标，没有精讲。这是整学科缺口，不是随机缺失。坐标题仍然是热度统计的分母，不能省。

## 怎么跑

### 小程序

用微信开发者工具打开 `考研数学第二大脑/mp`。`appid` 目前是 `touristappid`，上传前需换成自己的。

改语料后重新生成数据：

```bash
cd 考研数学第二大脑/mp
python3 scripts/build_data.py
```

### Web 原型

```bash
cd 考研数学第二大脑/v2
python3 ingest.py     # 仅在 raw/ 更新后需要
python3 build.py      # 产出 dist/真题库原型.html
```

## 设计上不能动的几条

1. **模型不判断「重不重要」**，重要性只能由真题统计得出，可核对。
2. **题与思路族的关系由用户点选**，不让模型猜。精讲里的「法一/法二」是同一道题的不同解法，**不是**思路族编号，别混。
3. **诊断用中位数不用均值**：每个考点都有几道压轴题永远做不出，均值会拖垮一个已掌握的考点，用户看到就会不信这个数。
4. **熟练度不采自评**，只记四档行为事实（独立做出/提示后做出/看答案才懂/还是不会）。
5. **考频表的 239 个考点与索引的 92 个考点不能自动合并**：名称匹配只有 8%，`泰勒公式` 会被错配到「根据通项公式求极限」。要合并必须人工做映射表。

## 已知限制

- **公式是 Unicode 近似，不是排版**：小程序没有 DOM，跑不了 KaTeX。`xᵐ`、`∫₀ˣ`、`lim_{n→∞}` 这类可用；矩阵、分段函数会失真。后续换 SVG 图或后端渲染。
- **题干只有 475 题**，粘线代/概率的题匹配会失准，需手动选考点（产品里已兜住）。
- **热度归一化系数是拍的**（n6/8），真实语料做大后要重校。
